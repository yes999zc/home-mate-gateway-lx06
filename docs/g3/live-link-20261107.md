## 2. 实机新事实（G2 取证未覆盖，全部实测）

1. **TLS 验证名是固定的 `echomuse-controller`**：设备按 IP 拨号，但 Go 客户端用固定 ServerName 验证证书——证书没有该 SAN 即 BadCertificate（设备日志原话 `x509: certificate is valid for …, not echomuse-controller`）。映射草案未记录；已并入本仓 runbook。
2. **register.device_id 是设备序列号**（`G090L91072732EXG`），不是房间设备名。适配器以 stable_id=配置值（dot2-d）北向呈现，wire id 只作记录。
3. **register.capabilities 实测 22 项**：`mic, speaker, leds, led_anim, buttons, oww_shadow, oww_trigger, button_hold, audio_mix, aec_hw_ref, oww_local_only, output_chain, wake_cue, volume_cue, remote_volume_arc, response_level, wake_mic, pairing, wake_word_off, sendspin, ble_connect, ref_uplink`。
   - **G5 答案：audio_mix 存在**（音乐 0x04/0x05 通道可用；v0.2 首版仍走 voice 单通道）。
   - **音量能力名是 `remote_volume_arc`**（无裸 `volume`）；volume_set/volume_state 实测可用。
   - aec_hw_ref/ref_uplink 存在＝2ch [mic|ref] 上行可用（未启用，hw_ref=false 首版）。
   - register 还携带 ambient_light/emmc/board/boot_id 等遥测字段（只入日志）。
4. **register.version = `20261105-volume-r1`**（与基线注册标签吻合；fw 呈现北向）。
5. **设备不回 ICMP**——ping 通不通不代表链路死活（本次排查的红鲱鱼）。
6. **设备控制面会周期性停回 pong >40s**（数据面麦克风流仍活）→ 适配器 keepalive 判死断开 → 设备约 2s 重拨恢复。自愈闭环成立；DOT 同款参数（15s ping/40s 死线）。flush 2s 确认窗若落在该窗口内 → stop_receipt 如实 unknown（实测两种都见过）。
7. **playback_stats.bytesRecv 按到达整帧计**（704 帧=176128B 实测精确吻合含补零尾帧），played_ms=bytesRecv/(48k×2)×1000 是消费侧观察，可能与发送时长差一个 prime 窗口。
8. **mic 硬件静音按钮**本地生效且会上报 mute_state（G2 观察一致）。
